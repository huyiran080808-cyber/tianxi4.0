# Demo 每轮交付检查清单

## 流程检查

- [ ] Demo 能正常打开。
- [ ] 刷新后进入预期页面。
- [ ] 主导航可点击。
- [ ] 主流程能从入口走到完成态。
- [ ] 关键弹窗、浮窗、toast 能正常出现和关闭。
- [ ] 输入框、按钮、tab、卡片选中态正常。

## 视觉检查

- [ ] 关键页面第一屏无明显错位。
- [ ] 关键文案没有错别字、旧词、乱码。
- [ ] 头像、icon、图片都显示正常。
- [ ] hover、active、selected、disabled 状态符合当前阶段要求。
- [ ] 滚动区域和浮窗没有遮挡关键内容。
- [ ] 深色背景下图标和文字对比度足够。

## 资产检查

- [ ] 新资产已放入 `custom-assets/`。
- [ ] 文件名可读、可追溯。
- [ ] CSS/JS/图片版本号已按需更新。
- [ ] 没有引用本机绝对路径。
- [ ] GitHub Pages 上资源也能加载。

## 代码检查

- [ ] `git status` 只包含本轮相关文件。
- [ ] JS 语法检查通过。
- [ ] `git diff --check` 无空白错误。
- [ ] 未改动无关页面或无关资产。

## 交付说明

- [ ] 已写清本轮变更范围。
- [ ] 已说明未处理问题。
- [ ] 已提交 Git。
- [ ] 已推送到线上分支。
- [ ] 已提供验收链接或提交 hash。
