# 静态 Demo 模板

这是可复制的新项目起步模板。适合快速做一个无需构建工具、可直接部署 GitHub Pages 的交互 Demo。

## 文件

- `index.html`：页面结构。
- `styles.css`：视觉样式。
- `script.js`：交互和数据。
- `custom-assets/`：项目资产目录。

## 使用方式

1. 复制整个 `template-static-demo/`。
2. 替换 `index.html` 中的项目名和页面结构。
3. 在 `script.js` 中维护页面数据和交互状态。
4. 把设计资产放进 `custom-assets/`。
5. 本地打开 `index.html` 验证。
6. 推送到 GitHub Pages。

## 原则

- 先写最少页面和最少交互。
- 内容数据集中放在 `script.js` 顶部。
- 关键节点加 ID，方便批注定位。
- 资源替换后更新版本号。
