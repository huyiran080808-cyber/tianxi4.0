# 浏览器批注模板

## 推荐格式

```text
问题：这里当前表现是什么问题？
期望：希望改成什么？
依据：设计稿链接 / 截图 / 资产文件名 / 具体数值
优先级：必须改 / 建议改 / 可延后
```

## 示例

```text
问题：输入框高度比设计稿矮，按钮位置偏下。
期望：输入框高度统一为 132px，底部按钮和右侧 icon 垂直居中。
依据：Figma node-id=xxxx，input.svg。
优先级：必须改。
```

## 好批注

- 指向具体元素。
- 一条批注只说一个问题。
- 明确期望改法。
- 附设计稿或资产。

## 不好批注

- “整体不像”。
- “再高级一点”。
- “这里有问题”但没有说明问题。
- 一条批注同时包含 5 个页面的修改。
